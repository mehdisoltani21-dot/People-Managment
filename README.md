## فعال‌سازی GitHub Pages
1. برو به Settings → Pages
2. Source را روی **Deploy from a branch** بگذار
3. Branch: **main**  |  Folder: **/ (root)**
4. Save کن
5. بعد از ۱–۲ دقیقه سایت بالا می‌آید
